# Lookup role

This local package exports the executable `lookup` agent via pi-subagents' supported `pi-subagents.agents` manifest. `settings.json` registers the package; native discovery reads its agent definition. Profile overrides select Terra/medium without replacing the role's narrow tools, fresh context or read-only acceptance role.

The agent uses local evidence and standalone Codex Web Run, retaining relevant project constraints, source citations and uncertainty. It has no shell, browser, mutation or orchestration tools and no artificial turn/tool/token budget. Its model and tool surface must be checked through actual native discovery and a fresh child; a settings entry alone does not prove executability or provider health.
